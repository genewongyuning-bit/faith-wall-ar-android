# FAITH Wall AR — Android 测试版

这是用于 Android 手机和平板的原生 ARCore 测试工程。

## 已包含

- 从设备相册导入 JPG、PNG、WebP 等图片
- 只识别竖直墙面
- 以米为单位设置打印宽度，高度按图片比例自动计算
- 中心准星定位并创建 ARCore 锚点
- 放置后锁定、重新放置、更换图片
- FAITH PRINTER 黑色、白色与蓝色品牌界面
- 中文跟踪状态提示

## 设备要求

- Android 7.0（API 24）或更高
- 设备须支持 Google Play AR 服务（ARCore）
- 建议在光线充足、带少量纹理的墙面测试

## 本地运行

1. 用 Android Studio 打开项目根目录。
2. 等待 Gradle 同步完成。
3. 连接支持 ARCore 的 Android 手机或平板。
4. 选择 `app` 配置并运行。

首次启动时，需要允许摄像头权限，并可能按系统提示安装或更新 Google Play AR 服务。

## 测试流程

1. 点击“导入图片”。
2. 用 `− / +` 设置实际打印宽度。
3. 缓慢移动设备扫描墙面，准星变蓝后对准目标中心。
4. 点击“放到墙上”。
5. 前后、左右移动设备，检查透视、锚点稳定性和真实尺寸。

## 云端构建 APK

工程包含 `.github/workflows/android-build.yml`。推送到 GitHub 的 `main` 分支后会自动构建 Debug APK，也可以在 Actions 页面手动运行。

## 当前测试边界

- 真实尺寸依赖 ARCore 对墙面的跟踪质量，弱光、纯色无纹理墙面会降低精度。
- 本测试版先验证“墙面识别 + 尺寸 + 锚定”主链路，尚未加入成品导出、项目保存和多人共享。
